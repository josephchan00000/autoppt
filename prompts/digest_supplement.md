# Stage 3 補充深讀 — 章名、原書用語、故事（每章跑一次）

這一章的深讀檔已經有了：`work/03_digest/{ch_id}.json`。這次**只補四個欄位**，
其餘欄位一個字都不要動；補完寫回同一個檔案。

**請只讀 `{chapter_file}` 這一章**，所有內容必須出自這一章的文字。

```json
{
  "chapter_title_en": "作者的原章名，照抄，不含章號（這一章是：{chapter_title_en}）",
  "chapter_title_zh": "章名中譯：{official_hint}",
  "key_terms": [
    {"en": "the price of time", "zh": "時間的價格", "page_ref": "p.21", "note": "作者用它指什麼（20 字內）"}
  ],
  "stories": [
    {"who": "John Law", "when": "1719–1720", "where": "巴黎",
     "what": "發生什麼，只用作者給的細節（80 字內）", "turn": "轉折（40 字內）",
     "so_what": "作者拿這個故事證明什麼（40 字內）", "page_ref": "p.77–85"}
  ]
}
```

數量：`key_terms` 5–10 個；`stories` 1–3 則。

## 品質底線

1. `key_terms` 必須是**作者自己的用語**：他造的詞、反覆用的比喻、章名裡的關鍵詞、
   他引用並採納的別人的話。一般教科書名詞（通膨、GDP、殖利率）不算。
   `en` 照抄原文；`zh` 是投影片會直接用的字，翻不出自然的中文就留空字串——
   **很爛的翻譯比原文更糟**，簡報會直接用原文。
2. `stories` 是有人物、時間、轉折的段落，不是論點的重述。`what` 只用作者給的細節
   （數字、地名、對話、誰對誰說了什麼），不要自己補；`so_what` 寫作者拿它證明什麼，
   不是你的評論。故事之後會進逐字稿，投影片只放大綱與示意圖。
3. `chapter_title_zh`：有官方中譯章名就照抄（上面已標）；沒有才自己翻；翻得不自然就留空。

## 輸出

把四個欄位併進 `work/03_digest/{ch_id}.json`，然後跑
`python scripts/03_digest.py --validate {ch_id}`。一次只處理一章。
