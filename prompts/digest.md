# Stage 3 — 逐章深讀（每章跑一次）

你正在為復華投信內部 60 分鐘讀書分享準備素材。

**請只讀 `{chapter_file}` 這一章**，不要引用你對這本書的既有印象，
所有內容必須出自這一章的文字。若這一章沒有提到某件事，就不要寫進來。

輸出 JSON，schema 如下（嚴格遵守，不要加欄位、不要 markdown 圍欄）：

```json
{
  "ch_id": "ch01",
  "title": "章節標題（拆章時的標題，含章號，照抄）",
  "chapter_title_en": "作者的原章名，照抄，不含章號",
  "chapter_title_zh": "章名中譯：有官方中譯本就抄官方譯名；沒有就忠實翻譯；翻不出自然的中文就留空字串",
  "one_line": "一句話講完這章在說什麼（30 字內）",
  "thesis": "這章的核心主張（80 字內，要是一個可被反駁的論點，不是描述）",
  "key_points": [
    {
      "point": "論點標題（12 字內）",
      "elaboration": "展開說明（100–150 字）",
      "book_evidence": "書中支持這論點的具體證據／案例／數據，要能對應原文",
      "page_ref": "原書頁碼或頁碼區間"
    }
  ],
  "key_terms": [
    {"en": "the price of time", "zh": "時間的價格", "page_ref": "p.21", "note": "作者用它指什麼（20 字內）"}
  ],
  "stories": [
    {"who": "John Law", "when": "1719–1720", "where": "巴黎",
     "what": "發生什麼，只用作者給的細節（80 字內）", "turn": "轉折（40 字內）",
     "so_what": "作者拿這個故事證明什麼（40 字內）", "page_ref": "p.77–85"}
  ],
  "quotes": [
    {"text": "值得上投影片的原文引句（50 字內）", "page_ref": "p.34"}
  ],
  "data_points": [
    {"claim": "書中提到的數據", "value": "數字", "as_of": "書中標示的年份", "page_ref": "p.34"}
  ],
  "counterpoint": "這章最站不住腳、或最值得挑戰的地方（80 字內）",
  "open_questions": ["需要外部資料才能回答的問題"]
}
```

數量規定：`key_points` 3–5 個；`key_terms` 5–10 個；`stories` 1–3 則；`quotes` 1–2 個；
`open_questions` 2–3 個。`data_points` 沒有就給空陣列，**不要編造數字**。

## 品質底線（任何一項不符就整份重寫）

1. `key_points[].elaboration` **不能是 thesis 的改寫**，必須提供 thesis 沒有的資訊。
   寫之前先問自己：「讀者只看 thesis，會不會已經知道這段在講什麼？」會，就重寫。
2. `book_evidence` **不可留空、不可寫「書中提到」這種空話**，要有具體內容：
   人名、公司名、年份、數字、實驗設計、故事情節任一種。
   ✗「書中提到這個現象很常見」
   ✓「作者引用 1998 年 LTCM 倒閉案，說明模型在尾端風險失效時的槓桿放大效果」
3. `counterpoint` 不准寫「本章論述完整」「作者論證嚴謹」之類的敷衍句。
   一定要指出一個**具體的弱點**：取樣偏誤、時空背景已變、反例存在、因果倒置、
   只有個案沒有統計，等等。
4. `open_questions` 必須是「**查得到資料的具體問題**」，不是哲學提問。
   ✗「人性是否真的無法克服？」
   ✓「台灣散戶 2020–2025 年的週轉率是多少？是否如書中所說高於美國散戶？」
5. `thesis` 必須是**可被反駁的論點**，不是描述。
   ✗「本章介紹資產配置的重要性」
   ✓「資產配置決定九成績效，選股與擇時的貢獻在扣除成本後接近於零」
6. `page_ref` 盡量填原書頁碼；章節檔 front-matter 的 `pages` 欄位是這一章的頁碼區間，
   據此推估。真的無法判斷才寫該章區間。
7. `key_terms` 必須是**作者自己的用語**：他造的詞、反覆用的比喻、章名裡的關鍵詞、
   他引用並採納的別人的話（"John Bull cannot stand two per cent"）。
   一般教科書名詞（通膨、GDP、殖利率）不算。`en` 照抄原文；`zh` 是投影片會直接用的字，
   翻不出自然的中文就留空字串，簡報會用原文——**很爛的翻譯比原文更糟**。
8. `stories` 是有人物、時間、轉折的段落，不是論點的重述。`what` 只用作者給的細節
   （數字、地名、對話、誰對誰說了什麼），不要自己補；`so_what` 寫作者拿它證明什麼，
   不是你的評論。這些故事之後會進逐字稿，投影片只放大綱與示意圖。
9. `chapter_title_zh`：先看 `work/04_author.json` 的 `book.chapters` 有沒有官方中譯章名，
   有就照抄；沒有才自己翻；翻得不自然就留空。

## 語言

繁體中文。專有名詞保留英文原文，首次出現寫「中文（English）」。
不使用對岸用語（賦能／抓手／閉環／顆粒度／打法／復盤／落地性／用戶／信息／質量）。

## 輸出

寫入 `work/03_digest/{ch_id}.json`。
**一次只處理一章、寫檔、再處理下一章**，不要一次把所有章節塞進 context。
寫完後跑 `python scripts/03_digest.py --validate {ch_id}` 確認 schema 與品質底線通過。
