# Stage 5b — 投影片文案潤飾

`05_outline.py` 已經從 `work/05a_guide.json` 長出 `work/05_deck.json` 的骨架（導讀體）。
每一頁都有 `role`（這頁在導讀裡的角色）、`section`（屬於哪一章）、`style`（文字頁的樣式）；
大綱頁還有 `story_hint`（這章選的故事，寫逐字稿用，不上投影片）。
**你的工作是潤飾文案、把【待填】補掉，不是重排結構。** 結構不對回去改 guide.json。

不要改動：`id`、`layout`、`kind`、`role`、`section`、`ch_id`、`note`（章名頁籤的原文註）、`sources[].url`。
可以改動：`title`、`subtitle`、`body`、`style`（三種之間換）、視覺欄位、`sources[].label`、`duration_sec`。
可以做：把一頁 content 改成視覺頁（加 `flow` / `table` / `split` / `timeline`，`kind` 改 `chart`），或反過來。
可以做：把一頁移到附錄（`role` 改 `appendix`、`duration_sec` 改 0、搬到結語之後）。**不要刪。**

## 每一種角色要寫什麼

| role | 頁 | 主標 | 內文 |
|---|---|---|---|
| `cover` | 封面 | 書名 | 副標＝全書主張的短版 |
| `author` | 作者是誰（2–3 頁） | 作者名／生涯一句話／評價一句話 | 背景／立場／為什麼寫；生涯與著作時間軸；評價／批評／獎項。**每一句都要對得到 `work/04_author.json` 的一筆** |
| `summary` | 執行摘要 | 主張短版 | `labeled`：主張／證據／意義。「證據」那條要帶全書最有力的一個數字 |
| `map` | 章序地圖 | 今天的路線 | 分部＋主線章的官方章名，不要改字 |
| `part` | 分部頁籤 | 中譯本的 Part 標題 | 無 |
| `divider` | 章名頁籤 | **官方中譯章名或原文**，不准改寫 | 無；`note` 是「第 N 章｜英文原名」，程式帶的 |
| `outline` | 大綱頁 | 這章的一句話結論，**用作者的話** | `chain`：作者在這章的推論 2–4 步 |
| `evidence` | 示意圖／重點頁 | 這張圖要說的結論 | 視覺（flow／timeline／split／table／原圖），或 `labeled` 重點 |
| `today` | 今天的數字 | 結論句 | 書中值 → 最新值（table）或台灣對照（split／labeled） |
| `implication` | 全書意涵 | 對長期投資的一句結論 | `labeled`：配置／折現率／風險預算／持有期間 |
| `counter` | 反方 | 反方主張句 | `labeled`：每條一個具體弱點（取樣、因果、反例、時空） |
| `closing` | 結語 | 一句收束 | 無 |
| `appendix` | 附錄 | 結論句 | 不計時、不需逐字稿，被問到再翻 |

## 【原書用字】← 這一版最重要的規則

投影片上的字要是**作者的字**，不是你的濃縮。

- 每一章的投影片至少要出現該章一個 `key_term`（`work/03_digest/chNN.json` 的 `key_terms`），
  `08_qa.py` 的「原書用字」檢查會抓。
- 主標優先用作者的句子：章名、`key_terms`、`quotes`。✗「利率與投機的關係」 ✓「約翰牛受不了 2%」
- 中譯附英文原詞：「時間的價格（the price of time）」。`key_terms[].zh` 是空字串的，直接用英文。
- 同義改寫是禁止項。能引原文就引原文；引句頁 `zh` 也要忠實，不要順。
- 故事**不上投影片**：`story_hint` 是給逐字稿用的，投影片放大綱、重點與示意圖。

## 【去 AI 味】← 使用者退過一次的地方

實跑《時間的代價》時使用者的原話：「用字不夠平易近人，太 AI 感」。
拆出來是三個具體毛病，`08_qa.py` 的「AI 味」檢查會逐頁抓（只 WARN，但都要修）：

### 1. 不要「名詞：名詞」

冒號句式寫起來快，三條排在一起就變成詞條表，不是話。
**一頁最多一條用冒號**，其餘改寫成有主詞有動作的句子。

- ✗ `監理套利：和法律同齡`
- ✓ `漢摩拉比訂了上限卻沒訂期間，套利和法律一樣老`
- ✗ `葛林斯潘接棒：Greenspan put、Goldilocks、Great Moderation`
- ✓ `葛林斯潘接棒之後，泡沫每隔幾年就換一個名字`

### 2. 一頁最多一個英文原詞

作者自己造的關鍵詞（`key_terms`）留原文，因為那是他的話；
其餘全部講中文。一句話裡塞三個英文詞，中文就被切碎了。

- ✗ `利息是 creative destruction 的煞車：像 NBA 的 shot clock`
- ✓ `利息是創造性破壞的煞車，像籃球的二十四秒進攻鐘`

### 3. 三條不要長得一模一樣

長度、句式、結尾都要有變化。三條都是 18 字、都用冒號、都以名詞結尾，
一看就是湊出來的排比。**先寫完三句話，再回頭把最像的那句改掉。**

### 4. 每一條都要有動作

沒有動詞的條列是名詞堆疊，聽眾要自己補動詞才讀得懂。

- ✗ `零利率下的估值扭曲與資本錯置`
- ✓ `零利率把估值撐高，資本就留在不該留的地方`

## 【標題】

- 主標一律寫成「**有結論的句子**」，不是名詞標籤
  - ✗「風險管理」　✓「風險預算該分配在部位，不在情緒」
  - ✗「資產配置的重要性」　✓「配置決定九成績效，選股貢獻扣成本後歸零」
- **章名頁籤例外**：頁籤就是官方章名或原文，不是結論句，也不准改寫（`08_qa.py` 對不在章名清單裡的頁籤判 FAIL）
- 主標 ≤ **14 字**；副標 ≤ **21 字**，副標負責補「為什麼／所以呢」
  （母片「內頁1-1」主標框是 36pt 單行、寬 6,840,760 EMU，約放得下 14 個全形字。超過會折成兩行壓到副標上。）
- 同一幕內的主標不要重複句型，連續三頁都用「X 才是 Y」會很呆
- 視覺頁的主標寫**這張圖要說的結論**，圖名放副標

## 【文字頁只准三種樣式】← 核心

**動筆前先問：這頁非得文字不可嗎？** 是機制就畫 `flow`、是對照就畫 `table` 或 `split`、
是時間刻度就畫 `timeline`。判斷表在 `prompts/visuals.md` 開頭。

真的要文字，**三選一**寫進 `style`。裸條列——三個彼此無關的平行事實排在一起——`08_qa.py` 判 FAIL。

### `chain` 論證鏈：用在機制、因果、推論

每一步接著上一步，讀起來是「因為…所以…因此…」。2–4 步，3 步最好。

```json
{ "style": "chain", "body": [
    {"text": "折現率貼近零時，固定股息的現值趨於無限"},
    {"text": "瑞士國家銀行股價因此兩年漲逾七倍，2018/4 收 8,380 法郎"},
    {"text": "升息後同一道算術反向：2026/9 收 3,130 法郎，跌逾六成"} ] }
```

- ✗ 三條互不相干的數字排在一起
- ✓ 每一條前面都能補上「因為／所以／結果」而不彆扭
- 序號 ①②③ 會自動加，不要自己寫

### `labeled` 標籤＋說明：用在對照、多面向拆解

每條一個 ≤5 字的標籤，後面接說明。2–3 條、標籤不重複。

```json
{ "style": "labeled", "body": [
    {"label": "書說", "text": "存款利率長期低於名目成長率，家庭補貼國企"},
    {"label": "今天", "text": "2026/8 一年期存款 1.5%，名目成長 4.6%，差距仍在"},
    {"label": "長期投資", "text": "官定利率的市場，折現率是政策變數，估值要另加風險溢酬"} ] }
```

- 標籤要回答「這一條是什麼」：✓「機制」「證據」「台灣」「今天」「代價」「書說」「最新」
- ✗ 序號當標籤（「一」「重點1」）、✗ 標籤和內文重複同一個詞

### `prose` 敘事段：用在有人物、時間、轉折的案例

1–2 段、每段 ≤90 字、至少一個具體物。讀起來是一個段落，不是把三條條列用句號接起來。

```json
{ "style": "prose", "body": [
    {"text": "1720 年約翰・羅（John Law）把法國利率壓到 2%，新錢先進了密西西比公司的股票，兩年內紙鈔發行量翻倍。"},
    {"text": "股價撐不住時他用新印的錢買回自家股票，撐了幾個月；泡沫破掉之後，法國一個世紀不再信任紙幣。"} ] }
```

### 什麼時候用哪一種

| 內容長什麼樣 | 用 |
|---|---|
| A 導致 B 導致 C | `chain`（步驟多、有迴圈就改畫 `flow`） |
| 兩三個面向各自一句 | `labeled` |
| 一個有情節的案例 | `prose` |
| 兩組東西對照 | `split` 或 `table`（視覺頁，不是文字頁） |

三種要**混用**：`08_qa.py` 對「七成以上都是同一種」會 WARN。
**連續最多 2 頁文字頁**，第 3 頁一定要是視覺頁、引言頁或大數字頁。

## 【內文通則】

- 每條 ≤ **40 字**（prose 每段 ≤ 90），每頁總字數 ≤ **160 字**；超過 QA 判 FAIL
- **一頁放 4 條時，每條再收到 ≤ 34 字**。卡片的字級是版面引擎按「一頁幾張卡、
  最長那條幾個字」自動算的：3 條以內大約 22–26pt，4 條而且每條都很長就會縮到 18pt，
  台下看不清楚。QA 會提醒「卡片縮到 18pt」——那是叫你砍字，不是叫你改門檻
- 每頁**至少有一個「具體物」**：數字、年份、案例名、金額、比例。全部都是抽象概念的頁面一律重寫
  - ✗「市場情緒會影響投資決策，投資人應保持理性」
  - ✓「2020/3 台股單月跌 14%，散戶淨賣超 380 億，三個月後全數回補」
- 三種樣式都**沒有第二層**（不要 `level: 1`）
- `labeled` 2–3 條，`chain`（大綱頁）2–4 步；3 是上限不是目標，2 條講得清楚就不要湊

## 【視覺頁】← 另讀 prompts/visuals.md

判斷順序：**書中原圖 > 外部機構原圖 > 流程圖／時間軸／對照表／雙欄 > 引言頁與大數字頁 >
自己畫的圖表**，完整規則與 deck.json 欄位寫法見 `prompts/visuals.md`。

字數上限**看它走哪個版面**：`image` / `table` / `split` 走內頁2-1，與內容頁相同（主標 ≤14、副標 ≤21）；
`flow` / `timeline` / `chart` 走空白內頁，比較寬（主標 ≤20、副標 ≤30）。

## 【資料來源】

- 每一頁都要有 `sources`（封面／頁籤／結尾除外，附錄也要）
- 書內容寫「《書名》p.XX」；書中原圖寫「《書名》書中圖表，p.XX」（骨架填的是 PDF 頁碼，要核對成原書頁碼）
- 外部資料寫「機構名（YYYY/MM）」，**同時保留 `url`** 進 deck.json 供 QA 檢查，投影片上只印機構名與日期
- 不要把 URL 寫進 `label`；不要編造來源——骨架裡的來源都來自 03/04 的檔案，沒有的就不要加

## 【語氣】← 這次要用哪一種，看 deck.json

`work/05_deck.json` 的 `meta.tone_directive_slide` 就是這次選定的語氣規則，
**動筆之前先讀它**，整份稿子照著寫。語氣規則的原文在 `config/project.yaml` 的 `tone_presets`。

## 【語言】

- 繁體中文為主，專有名詞保留英文原文，首次出現寫「中文（English）」
- 不使用「賦能、抓手、閉環、顆粒度、打法、復盤、落地性、用戶、信息、質量」這類對岸用語

## 【時間與附錄】

`duration_sec` 是配速指引，不是門檻；QA 對總時長與每頁字數只 WARN。
指引：頁籤 ≤20 秒、引言／大數字 ≤30 秒、單頁 ≤120 秒、序幕不超過總時長 15%。
超時的正確做法：先把次要證據頁移到附錄，不要刪；再考慮 `python tools/repace_deck.py` 重新配速。
